# Releases

Signed and notarized macOS builds of tools whose source is not public.

| Tool | What it is | Install |
|---|---|---|
| teamscli | Microsoft Teams and Outlook from the command line | `brew install cgrossde/tap/teamscli` |
| Klar | Personal AI search and chat for macOS, one hotkey away | `brew install --cask cgrossde/tap/klar` |

Downloads are on the [releases page](https://github.com/cgrossde/Releases/releases). Each release is tagged `<tool>-v<version>`.

All binaries are signed with a Developer ID certificate and notarized by Apple.
